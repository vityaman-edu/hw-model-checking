# Регулируемый перекресток

Имеется регулируемый перекресток, в котором пересекаются 2 дороги.

- Каждая дорога содержит по одной полосе в каждую сторону.
- По каждой дороге едут машины и хотят проехать перекресток.
  - Каждая машина хочет проехать либо прямо, либо направо.
  - Проезд перекрестка происходит за 2 единицы времени.
- На перекрестке работает светофор.
  - Если свет зеленый, то машина может ехать вперед и направо.
  - Если горит красный свет, то разрешен поворот направо, если слева нет машины.
- Потоки машины - случайные, но машины подъезжают к каждой полосе перекрестка не чаще,
  чем 1 машина за 2 единицы времени.

Необходимо рассмотреть несколько режимов работы светофора:
- симметричный - попеременное переключение сигналов, например
  3 единицы времени в одном направлении, 3 в другом.
- асимметричный.

Проверки:
- Невозможность проехать на красный свет
- Отсутствие аварий
- Отсутствие пробок

Реализация:
- Волшебный перекресток:
  ```


        N           |
        o           |
        o           |
  E o o o o o W     | W 0 1 2 3 4 <- forward
        o           |       3
        o           |       4     <- right
        S           |
  ```
- Есть желтый свет светофора

- Поворот направо за одну единицу
